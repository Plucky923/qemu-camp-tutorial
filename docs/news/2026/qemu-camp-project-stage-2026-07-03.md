# QEMU 训练营 2026 项目阶段正式开启

!!! note "主要贡献者"

    - 通讯：[@bbbbbq](https://github.com/bbbbbq)

2026 年 7 月 3 日，GTOC 发布 QEMU 训练营 2026 项目阶段启动消息。近 40 名学员在完成导学阶段、基础阶段和专业阶段后，进入本期训练营最贴近真实工程实践的项目阶段。

项目阶段意味着学员将从课程学习和实验提交，进一步走向真实开源项目协作。接下来，同学们会以小组形式参与具体项目方向，在导师和助教指导下完成需求理解、任务拆解、方案设计、代码实现、调试验证和阶段展示。

## 四个项目方向

本期项目阶段设置四个方向，覆盖 AI 加速、自动化外设建模、跨平台运行环境、RISC-V、嵌入式系统与星务计算等主题。

### 建模 AI 加速卡

该方向围绕 CXL Type-2 加速器建模、跨平台 GPGPU 仿真和 QEMU 设备模型展开，重点关注 Guest 侧 CUDA 调用、libcuda shim、CXL GPU 命令协议、QEMU PCIe/CXL 设备模型以及 Host 侧 hetGPU 后端之间的完整链路。

项目任务将从功能验证、后端存储优化、ternary kernel 动态 codegen、多节点解耦推理等方向推进，适合对 AI Infra、GPU 建模、CXL、体系结构和 QEMU 设备模拟感兴趣的同学。

### 大模型赋能外设建模

该方向关注 AI Agent 在 QEMU 外设建模流程中的实际能力。项目会以硬件参考手册、datasheet 和开源驱动代码为输入，探索寄存器结构抽取、行为语义推断、状态机重建、中断与事件依赖建模、跨外设交互分析等任务。

项目将分为 STM32F103 建模和 Agent 构建与 Benchmark 两个阶段，重点检验生成模型是否能被真实系统软件使用，并通过固件样例、驱动访问回放或单元测试形成验证闭环。

### 应用跨平台转译

该方向围绕 Wine-CE、QEMU、Box64 等技术展开，探索 x86 应用到 RISC-V 平台的兼容运行。学员需要理解 Windows 应用、Wine 兼容层、QEMU 或二进制翻译组件、宿主 Linux 环境之间的运行关系。

项目任务包括 QEMU / Box64 / Wine 版本更新，Windows 应用与游戏扩展测评及问题修复，以及 Wine RISC-V 支持完善。它面向希望深入理解系统软件、跨平台运行机制和 RISC-V 生态的同学。

### 数字星务计算机

该方向以 QEMU K230 board 为基础，探索面向星务计算场景的系统建模。项目将从单节点启动扩展到多节点互联、外设补全、星务安全模块支撑和仿真观测验证。

项目任务包括 RustSBI 适配 K230、完善 K230 外设建模，以及构建面向星务安全模块的仿真实验场景。它适合对 RISC-V、嵌入式系统、航天软件、高可靠计算和复杂系统建模感兴趣的同学。

## 从实验走向开源协作

项目阶段不再只是完成固定步骤的实验，而是面向开放问题开展持续推进。学员需要阅读真实代码和文档，拆解复杂问题，定位运行错误，与导师、队友和社区协作，并把学习成果转化为可展示、可延续、可贡献的开源成果。

QEMU 训练营由清华大学陈渝老师、李明老师倡议发起，格维开源社区与华中科技大学开放原子开源俱乐部联合主办，OpenCamp 社区协办。本次训练营也得到苦芽科技、甲辰计划、腾讯云 CNB 社区、嘉楠开发者社区、Leo Linux 社区等合作单位支持。
