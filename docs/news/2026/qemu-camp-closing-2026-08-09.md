# QEMU 训练营 2026 圆满结营：从 QEMU 学习走向基础设施实践

!!! note "主要贡献者"

    - 通讯：[@zevorn](https://github.com/zevorn)

2026 年 8 月 9 日晚，QEMU 训练营 2026 结营仪式在线举行。经过导学、基础、专业和项目阶段的学习与实践，本期训练营完成了阶段性目标。结营仪式集中展示了学员项目成果，复盘了训练营的运营实践，并围绕下一期建设方向展开交流。

## 项目成果：从学习走向真实工程

本期项目阶段将 QEMU 学习延伸到真实的系统软件和基础设施问题。结营分享重点展示了 K230 全链路启动适配、CXL 架构下 AI 加速卡建模等项目的阶段性成果。

### K230 全链路启动适配

K230 项目围绕上游需求完成了模型拆分与适配：将原有模块拆分为通用 SSI 和 DWCSSI 模型，以支持不同厂商集成 SPI IP 核的 SoC，并针对不同版本 IP 核完成适配。

项目同时打通了 K230 的冷启动链路。团队收集并合并现有补丁，完成从 Flash、BootROM、SPL、U-Boot、OpenSBI 到 Linux 的全链路启动验证。通过仅调整官方 SDK 中少量适配宏和启动方式，项目能够保留原生 SDK 的配置与产出物，降低模拟启动的使用复杂度。

### CXL 架构下 AI 加速卡建模

CXL 项目以大模型推理场景为验证目标，在 llama.cpp 框架下探索 CXL 协议与 Herd GPU 指令翻译对推理性能的影响。项目完成了从 Guest 虚拟机内指令劫持、CXL Server 转发，到 Host 端 Herd GPU 转译并调用真实显卡的完整链路适配。

在工程协作方面，项目联合多位学员解决了大模型存储和编译产物持久化等问题，使用 Git LFS 管理约 232 GB 的模型文件，并基于 Cumulab 实现编译产物的镜像化复用，为后续迭代提供了更稳定的开发基础。

这些项目成果体现了训练营从概念学习、实验验证走向真实工程协作的变化：学员不仅需要理解 QEMU 的内部机制，还要面对上游适配、系统启动、异构计算链路和大型工程协作中的实际问题。

## 运营复盘：从技术训练营走向开源社区

结营复盘显示，本期训练营的定位已从单一的 QEMU 技术探索，逐步升级为以 QEMU 为基础设施底座的基础软件探索，覆盖 AI Infra、传统 CS Infra 等多个方向。

本期训练营在 RISC-V 上游社区的 K230 相关贡献占比超过 50%，贡献的参与人数和质量较去年均有提升。运营上继续采用开源导师与往届优秀学员共同参与的社区化模式，在没有商业化投入的情况下形成了持续传承的人才培养机制。

复盘也总结了当前仍需改进的问题。基础和专业阶段使用的 GitHub Classroom 存在一些长期未修复的问题，影响了学员的使用体验；现有讲义专业性较强、学习跨度较大，部分零基础学员在入门阶段面临一定困难。这些反馈将成为下一期课程和平台优化的重要依据。

## 下一期规划：长期参与、内容重构与项目延续

下一期训练营计划从一年一度的短期集中活动，逐步转向长期、可持续参与的社区化模式。学员可以根据自身节奏参与学习，在需要时暂停，之后再回到社区继续推进，不再受固定周期的限制。

平台建设方面，社区将推进一站式官方站点，逐步集成阶段任务管理、代码仓库管理、人员信息统计和实验跑分天梯榜等功能，降低运营成本，提升学习过程的反馈感和参与感。

内容体系也将进一步重构：在讲义中补充通俗化类比、代码示例和配套小实验，平滑不同阶段之间的学习梯度；结合学员贡献的博客完善课程内容，并增加 Agent 使用指南和答疑类视频，帮助学员在 AI 辅助开发时代建立更科学的学习和实践方法。

项目方向将继续围绕现有项目迭代、AI Infra 探索和新型硬件板卡适配展开，同时规划系统化的 Zephyr 开源实践训练营。训练营还将与“一生一芯”等社区形成定位互补，并邀请本期优秀学员持续参与项目维护和训练营建设，推动社区形成长期正向循环。

## 结语：结营不是终点

QEMU 训练营 2026 的结营，标志着本期集中学习阶段告一段落，也标志着更多学习成果开始进入真实开源项目和社区协作。学员在训练营中积累的代码、文档、实验和项目经验，将继续在后续项目迭代与开源贡献中发挥作用。

从 QEMU 内部机制，到 RISC-V 启动链路、AI 加速卡和系统基础设施，训练营正在从一套课程逐步成长为连接学习、实践与开源协作的社区平台。期待更多同学加入后续建设，在长期实践中共同拓展系统软件与开源硬件的边界。
