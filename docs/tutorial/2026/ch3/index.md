# 项目阶段学习资料

项目阶段的讲义围绕四个项目方向补充背景知识、技术路线和延伸阅读。这里回答“开始项目之前需要理解什么”；具体任务、协作方式、考核标准与交付物统一放在[项目阶段实验][project-stage]中。

!!! tip "课程文章"

    - [数字星务计算机](qemu-k230.md)：K230 machine、启动链路、设备建模与上游贡献流程。
    - [建模 AI 加速卡](qemu-cxlemu.md)：CXL Type-2、CXLMemSim、Concordia 与 ternary 推理链路。
    - [大模型建模外设](qemu-agent.md)：从硬件资料和驱动代码到寄存器、行为、中断与测试模型。
    - [应用跨平台转译](qemu-wine-ce.md)：Wine、QEMU user 与 Box64 协作的跨架构运行机制。

!!! info "建议学习方式"

    先阅读所选方向的课程文章，再回顾文章列出的基础与专业阶段讲义，最后进入对应的项目任务页。项目过程中遇到新的机制问题时，可以回到这里补齐知识，而不必把任务说明当作教材使用。
